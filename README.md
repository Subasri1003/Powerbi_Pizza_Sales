# Pizza Sales Analysis Dashboard using Power BI

### Project Overview
This project focus on analyzing pizza sales data to uncover key business insights. The data was cleaned and transformed using SQL, and an interactive dashboard was built using Power BI to visualize sales performance, customer behavior, and product trends.

### Objectives
1. Analyze overall sales performance
2. Identify top-performing categories and product
3. Understand customer ordering patterns
4. Discover peak order hours and demand trends

### Tools and Technologies
1. SQL (Data Cleaning & Joins)
2. Power BI (Data Visualization & Dashboard)

### Data Processing
1. Cleaned raw data using SQL
2. Handled missing and inconsistent values
3. Joined multiple tables to create a structured dataset

### Dashboard Insights
1. Revenue is driven by a few top categories
2. Peak orders occur during evening hours
3. Large-size pizzas are most preferred
4. Most orders contain single quantity items
5. sales trends vary across time periods

### Key Learnings
1. Hands-on experience in SQL data cleaning and Joins
2. Bulit interactive dashboards using power BI
3. Improved understanding of data-driven decision making

### Conclusion
This project demonstrates how raw data can be transformed into meaningful insights using SQL and Power BI, helping businesses make informed decisions.
